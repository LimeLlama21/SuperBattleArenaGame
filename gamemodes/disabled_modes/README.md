# Disabled Modes

Place game mode scripts (e.g., `trains.gd`, `deathmatch.gd`, `best_of_five.gd`, `team_deathmatch.gd`) or subdirectories here to disable them.
Game modes located in this directory will be automatically excluded from the mode selection box in the lobby.

You can also configure enabled and disabled modes directly in `res://gamemodes/enabled_modes.gd`.
